# ギアモン傭兵ガチャシミュレーター

ギアモン傭兵ガチャの獲得結果をシミュレーションします。
こちらのリンクから遊べます
https://gear-mon-mercenary-gacha-simulator-swart.vercel.app/

## 仕様概要

- **1倍転送**: 1回の抽選結果を獲得する
- **10倍転送**: 1回の抽選結果を10倍獲得する
- 転送神珠を倍率分ずつ消費しながら、指定数が尽きるまで繰り返し
- **無料追加転送**: 1回の転送内で、当該抽選の獲得数が条件（初回5個以上）を満たすと無料で再抽選。条件は追加のたび+1される
