# 転送シミュレーター

転送神珠を消費したときの獲得結果を、確率表に基づきシミュレーションします。

## ローカルで動かす

```bash
cd gacha-sim
npm install
npm run dev
```

## 仕様概要

- **1倍転送**: 1回の独立抽選結果（各アイテムを確率表どおり個別判定）
- **10倍転送**: 上記の獲得数を10倍
- 転送神珠を倍率分ずつ消費しながら、指定数が尽きるまで繰り返し
- **無料追加転送**: 1回の転送内で、当該抽選の獲得数が条件（初回5個以上）を満たすと無料で再抽選。条件は追加のたび+1。上限は「無料追加転送回数」

確率・カテゴリ色は [`src/data/catalog.ts`](src/data/catalog.ts) を参照。

## 公開（Vercel）

専用リポジトリのルートに本フォルダの中身を push。Root Directory 空、`npm run build`、output `dist`。詳細は [`vercel.json`](vercel.json)。
